# Hogar Playa · Android 1.1.0

Paquete de instalación para Android 8 o posterior.

- **Hogar_Playa.apk**: aplicación firmada. Abre el archivo en GitHub y pulsa Descargar archivo sin procesar.
- **Hogar_Playa_Instalacion.zip**: APK, script completo de Google Sheets, manual y comprobaciones.
- **Hogar_Playa.apk.sha256**: huella del archivo APK.

La aplicación permite crear perfiles, registrar sin conexión y sincronizar con una hoja propia. Incluye planificación de pagos CUP y protección USD. La conexión y las notificaciones se activan siguiendo Manual_Android.md, incluido en el ZIP.

Los archivos no contienen credenciales de conexión ni movimientos financieros reales.
