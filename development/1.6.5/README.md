# Hogar finanzas 1.6.5 — descarga TLS compatible

El error reportado ocurre dentro del descargador de Android durante la lectura TLS, antes de validar la APK. Las descargas publicadas se han comprobado desde el entorno, lo que no reproduce la conexión del teléfono.

La nueva ruta usa TLS 1.2 con confianza y validación de nombre del sistema. Prefiere ECDHE/ChaCha20 cuando está disponible y admite ECDHE/AES-GCM; no habilita CBC ni protocolos antiguos. Solicita identidad sin compresión y cierre de conexión. Reintenta hasta tres veces errores de lectura TLS, EOF, socket y timeout, siempre con conexión y archivo temporal nuevos; descarta parciales. No reintenta errores de certificado, handshake, redirecciones, tamaño excedido o respuesta HTTP incorrecta. Solo acepta la URL exacta de APK del repositorio y el límite original de 50 MiB. No elimina comprobaciones TLS.

CompatibleUpdate reutiliza la política cacheada y el verificador original AppUpdates.verify, que comprueba tamaño, SHA, paquete, versión, compatibilidad y certificado; solo publica downloadedHash después de verificar y guardar la candidata. El instalador original conserva sus comprobaciones y su confirmación Android. Una descarga se ejecuta en su propio hilo, conserva el indicador de progreso original y no bloquea la cola de operaciones financieras. Las acciones nuevas pasan por la autenticación diaria/perfil del puente. Ante error se ofrece Descargar con el navegador mediante una ruta HTTPS cerrada de GitHub, sin navegación WebView arbitraria.

Primera instalación de esta corrección: abrir el enlace de la APK 1.6.5 en Chrome e instalar encima. El descargador de las versiones anteriores no recibe la corrección hasta instalarla. No desinstalar ni borrar datos. No cambia Apps Script.

Construcción: `python3 development/1.6.5/build.py`, con base 1.6.4 y herramientas con hash fijado. Solo se recompila código propio escrito a mano. native_build compara las clases originales después de ensamblar; no modifica AppUpdates, UpdatePolicy, el instalador ni las clases financieras. Se modifica HouseholdFeatures y se añaden CompatibleUpdate/UpdateTransfer y auxiliares. Los stubs no se empaquetan. Se conserva firma, identidad y recursos compilados; app.js dirige la descarga al comando nuevo y añade alternativa de navegador.

Pruebas JVM: compilar UpdateTransfer.java y tests/UpdateTransferTest.java y ejecutar cu.hogarplaya.UpdateTransferTest. Simula BAD_DECRYPT tras bytes parciales, errores persistentes, certificados, EOF, redirecciones y límites, comprobando limpieza, nuevos archivos y TLS1.2/AEAD. Chromium verifica comandos nuevos y las funciones anteriores. Tests Android en emulador identificado validan la configuración TLS y el verificador/instalador original con una candidata futura ficticia local y su versión alterada. Las APK de instrumentación y fixture nunca se publican. No se prueba sobre datos ni dispositivos reales del usuario. La desaparición del fallo en ese teléfono necesita confirmación tras instalar la corrección.
